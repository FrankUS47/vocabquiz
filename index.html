檔案只會在你的瀏覽器裡讀取，不會上傳到任何地方，網站也不會記錄；重新整理頁面後需再載入一次。

檔案格式說明 
【格式一：文字檔 .txt（UTF-8）】
# 我的題庫名稱            ← 單一個 # 是題庫名稱（可省略）
## 第1課                  ← 兩個 ## 是群組名稱（課、類別、單元都可以）
apple|蘋果               ← 每行：英文|中文
borrow|借入|v.           ← 可加第三欄：詞性（n. v. adj. adv. 等，多個用 / 連接）
customs/immigration|海關/移民關   ← 一格有兩個同義字用 / 連接
## 第2課
quiet|安靜的|adj.
// 以 // 開頭的行是註解，會被忽略

【格式二：試算表另存的 .csv（UTF-8）】
欄位順序：群組,英文,中文,詞性
第1課,apple,蘋果,n.
第1課,borrow,借入,v.
詞性可以空白；若只有兩欄（英文,中文），群組名稱會用檔名。
第一列若是「群組,英文,中文,詞性」的標題列，會自動略過。
在 Excel 請選「另存新檔 → CSV UTF-8（逗號分隔）」。

題數超過範圍內的題目數時，會重複出題。「詳解」按鈕要按了才會顯示題目翻譯與解析。
